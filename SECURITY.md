# Security

Please do not report vulnerabilities in public issues. Send a concise report to
the repository maintainers with reproduction steps, impact, and any relevant
logs or proof of concept. Do not include secrets or personal data.

Raiker is local-first and governed by policy, capability gates, approval
controls, and audit records. See [docs/SECURITY_ARCHITECTURE.md](docs/SECURITY_ARCHITECTURE.md)
for the implemented security boundaries and [docs/SECURITY_AND_POLICY.md](docs/SECURITY_AND_POLICY.md)
for operating rules.
