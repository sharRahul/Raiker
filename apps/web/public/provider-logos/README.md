# Provider logo sources

These assets are bundled unchanged and used only to identify the selected
provider next to its model. They do not imply endorsement or sponsorship.

| Provider | Asset source | Usage basis |
| --- | --- | --- |
| Anthropic | [Anthropic press kit](https://www.anthropic.com/press-kit) | Published media asset |
| Ollama / Ollama Cloud | [Ollama logo in the official repository](https://github.com/ollama/ollama/blob/main/docs/ollama-logo.svg) | Repository asset (MIT-licensed project) |
| OpenRouter | [OpenRouter official integration demo](https://openrouterteam.github.io/sign-in-with-openrouter/) | Published integration SVG |
| Hugging Face | [Hugging Face brand assets](https://huggingface.co/brand) | Official downloadable asset |
| OpenAI | [OpenAI Blossom](https://commons.wikimedia.org/wiki/File:OpenAI_logo_2025_(symbol).svg), attributed to OpenAI | Exact square symbol; subject to [OpenAI's marks terms](https://openai.com/brand/) |
| Google | [Google hosted brand icon](https://www.gstatic.com/images/branding/product/ico/googleg_lodp.ico) | Official brand asset; subject to Google's brand-feature guidance |

The neutral fallback is intentional for local/custom endpoints without a
published, redistributable provider mark.
