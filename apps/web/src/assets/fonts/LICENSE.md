# Bundled fonts

Both families are bundled locally (latin + latin-ext variable-weight woff2
subsets) so the web app loads no external fonts and works fully offline.

| Family | Files | Weights | License |
|---|---|---|---|
| Manrope (Mikhail Sharanda) | `manrope-latin.woff2`, `manrope-latin-ext.woff2` | variable 200–800 | SIL Open Font License 1.1 |
| JetBrains Mono (JetBrains) | `jetbrains-mono-latin.woff2`, `jetbrains-mono-latin-ext.woff2` | variable 100–800 | SIL Open Font License 1.1 |

- Manrope: <https://github.com/sharanda/manrope>
