# Prompt — M3: Prompt/Session Workflow + STOP Switch

You are implementing **Milestone 3**. Read `03_API_CONTRACTS.md` and `02_SECURITY_UX.md`.
Branch `claude/raiker-governed-agent-ui-zsqqt6`.

## Goal
Let a user submit a prompt and watch the governed gather→plan→act→verify turn stream live, and
make the STOP switch real (cancel at safe boundary).

## Backend
- `POST /api/prompts` — build a full `PromptEnvelope` with `ClientMetadata(type="web_ui")`, call
  `AgentGateway.submit_prompt_async`; return serialized `AgentResponse`.
- `GET /api/prompts/{turn_id}/stream` — SSE over `AgentGateway.astream_prompt` (text deltas +
  lifecycle, terminating in `FINAL`). Same authority as submit.
- `POST /api/interrupts` — build `InterruptAction`, call
  `InterruptController.apply_at_safe_boundary` / `TaskManager.cancel_task`; **human-only**; emits
  `interrupt_received`/`safe_boundary_reached`/`task_cancelled`. Semantics: safe-boundary, not kill.
- `GET /api/tasks` already added in M2 (ensure it lists active tasks for the STOP switch).

## Frontend
- `ChatTurnTimeline`: phase rows (gather/plan/act/verify) with status, timestamp, policy decision,
  tool calls, verification result; consume the SSE stream.
- `ActionProposalCard`: proposed tool/action, risk level, affected files/resources,
  requires-approval badge, policy reason, preview/diff.
- Show `AgentResponse.status=failed` + policy denials inline (plain English via `reason_code` map).
- Wire the STOP switch: confirm dialog → `POST /api/interrupts {all:true, action_type:"cancel"}`;
  render the resulting events. Copy must say "next safe boundary, not instant force-kill."

## Tests
- Prompt lifecycle emits `prompt_received`…`turn_closed`; invalid envelope → `failed`.
- Interrupt cancels active tasks at safe boundary + emits events; **AI principal rejected**.
- Frontend: timeline renders phases from a fixture stream; STOP confirm calls the client.

## Don't
Don't execute tools outside the governed path; don't imply instant kill; don't bypass approval.

Full validation gate green (Python + frontend). Commit + push.
