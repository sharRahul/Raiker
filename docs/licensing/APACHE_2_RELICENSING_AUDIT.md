# Apache-2.0 relicensing audit

Audit date: 2026-07-18
Audited revision: `9f018ec142f8f1937e52bf8179fa0f07eb84a3be`

## Conclusion: no material relicensing blocker identified

Rahul Sharma confirmed that the `Claude`-attributed commits were generated by
Claude Code while editing this repository under a Claude Pro subscription.
Claude is therefore a development tool, not an independent contributor.
Anthropic's Consumer Terms assign its right, title, and interest (if any) in
outputs to the user, subject to the terms. On that basis, this review found no
material relicensing blocker. This is a repository review, not legal advice.

## Current state and scope reviewed

At the audited revision, the root `LICENSE` and `README.md` described Raiker as
MIT-licensed, and Python and JavaScript manifests had no project licence field.
This licensing change replaces that project metadata with Apache-2.0; it does
not alter the terms of previously released MIT versions.

Reviewed tracked repository material, including Python packages, scripts,
tests, documentation, GitHub Actions workflows, root and web package metadata,
the web app and its lockfile, assets, fonts, icons, and Git history (authors,
co-authors, merge commits, and commit trailers). No co-author or DCO trailers
were found. Local build artefacts, virtual environments, and installed
dependency directories were excluded from first-party provenance analysis.

## Third-party, assets, fonts, and dependencies

- No tracked `vendor/` or equivalent copied-source directory, separate
  third-party notice file, or first-party source-file copyright/SPDX notice was
  found. This does not establish that no copied material exists.
- The web app bundles Manrope, JetBrains Mono, and Source Serif 4 font subsets.
  Their attribution and SIL Open Font License 1.1 status are recorded in
  `apps/web/src/assets/fonts/LICENSE.md`; those notices must be preserved and
  the fonts must not be relicensed as Raiker code.
- Raiker icon and web image assets are tracked and materially touched by the
  `Claude` commits above. No external asset provenance or relicensing grant was
  found in the repository, so they are included in the authority gap.
- Python dependencies are declared in `pyproject.toml` without a lockfile.
  The web `package-lock.json` records dependency licence fields including MIT,
  MIT-0, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, BlueOak-1.0.0, and
  Python-2.0; no package entry lacks a licence field. Dependencies retain their
  own licences and would not be relicensed by a project-licence change.
