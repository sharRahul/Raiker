# Quiet UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Simplify frontend copy, remove Source Serif, and restore green non-release workflows.

**Architecture:** The global stylesheet owns font policy. Svelte views and components own visible static copy. CSS source tests prevent typography regressions, while the Python wire type changes without changing API JSON.

**Tech Stack:** Svelte, TypeScript, Vitest, CSS, Python, mypy, pytest, Rust/Cargo, GitHub Actions.

## Global Constraints

- Manrope is the interface font; JetBrains Mono is reserved for machine-readable text.
- Source Serif declarations, tokens, and assets are removed.
- Retain safety, approval, error, validation, status, and accessibility text.
- Do not stage pre-existing worktree changes.
- Push only after fresh local verification succeeds.
